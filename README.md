# Proyek Analisis Data: Bike Sharing Dataset

## Deskripsi Proyek
Proyek ini bertujuan untuk melakukan analisis data pada Bike Sharing Dataset untuk menemukan pola penyewaan sepeda berdasarkan kondisi cuaca dan waktu.

## Dataset
- `day.csv`: Data harian penyewaan sepeda.
- `hour.csv`: Data per jam penyewaan sepeda.
